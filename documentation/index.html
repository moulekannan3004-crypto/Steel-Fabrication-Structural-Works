Colors & Typography

All colors are centrally managed in assets/css/style.css via CSS Variables:

:root {
  /* Brand Palette */
  --primary: #142B45;        /* Deep Navy Blue */
  --secondary: #64748B;      /* Steel Grey */
  --accent: #F97316;         /* Industrial Safety Orange */
  --accent-hover: #EA580C;
  --bg-body: #F8FAFC;
  --bg-surface: #FFFFFF;
  --text-main: #1E293B;
  --text-muted: #64748B;
  --border-color: #E2E8F0;
}

To change the safety orange accent color throughout the entire template, simply edit --accent in assets/css/style.css.

Light and Dark Mode Engine

The template features a persistent theme toggle button in the header. The theme state is stored in the browser's localStorage under the key steelcraft_theme.

To force dark mode by default on your server, simply set the attribute on the <html> element:

<html lang="en" data-theme="dark" data-bs-theme="dark">

LTR & RTL Direction Support

SteelCraft supports Right-to-Left (RTL) languages like Arabic, Hebrew, and Persian. Clicking the "RTL" button mirrors all margins, breadcrumbs, icons, offcanvas drawers, and form alignments automatically.

To serve an RTL page natively, set:

<html lang="ar" dir="rtl">

Forms & Backend API Integration

All forms (Contact, Project RFP, Login, Register, Newsletter) contain client-side validation and responsive feedback alerts.

To wire up the Project RFQ form to your REST API or backend script (Node.js, PHP, Python, Webhook):

  1. Open assets/js/forms.js.
  2. Locate projectEnquiryForm.addEventListener('submit', ...).
  3. Replace the setTimeout block with your fetch() or axios call:
// Example Backend API Integration in assets/js/forms.js:
const formData = new FormData(projectEnquiryForm);

fetch('/api/v1/enquiries', {
  method: 'POST',
  body: formData
})
.then(response => response.json())
.then(data => {
  // Show success alert
  document.getElementById('projectFormAlert').className = 'form-alert success d-block';
  document.getElementById('projectFormAlert').innerHTML = '<strong>Success!</strong> Your quote reference is ' + data.id;
  projectEnquiryForm.reset();
})
.catch(error => {
  console.error('API Error:', error);
});
